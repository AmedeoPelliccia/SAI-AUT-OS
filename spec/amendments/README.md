# spec/amendments/ — Ratified Amendments

**Status:** Normative · **Layer:** Specification · **Spec:** v1.0.0-draft.1

Only ratified amendments live here, one file per amendment, numbered and immutable once merged. Amendments supersede; they never rewrite (constitution/AMENDMENT-PROCESS.md, rules S1–S3).

## What belongs here

- `A-0001-<slug>.md`, `A-0002-<slug>.md`, …

## What must NOT go here

- Drafts or proposals (→ `spec/rfcs/`)
