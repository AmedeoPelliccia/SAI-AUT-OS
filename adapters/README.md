# adapters/ — Ecosystem Bindings

**Status:** Non-normative · **Layer:** Integration · **Spec:** v1.0.0-draft.1

Bindings that map external ecosystems' mutable state onto registered Adaptive Component types, so existing stacks can be governed without modification. An adapter never makes governance decisions — it only exposes state and applies authorized CCIs.
