# Registry — Adaptive Component Types

**Status:** Normative · **Layer:** Interoperability · **Spec:** v1.0.0-draft.1

Reservation rules: new entries MUST be added only via a ratified RFC
(see `spec/rfcs/`). Entries are never deleted — they are deprecated by
amendment and remain resolvable forever. IDs are lowercase kebab-case.

| ID | Name | Description | Status | Defined by |
|---|---|---|---|---|
| `memory` | Memory | Persistent or working memory stores attached to the system | seed | RFC-0000 |
| `lora-adapter` | LoRA / Adapter | Parameter-efficient adapter weights layered on the Foundation Core | seed | RFC-0000 |
| `rag-index` | RAG Index | Retrieval corpora and their index structures | seed | RFC-0000 |
| `tool-binding` | Tool Binding | Tools/functions exposed to the system and their permissions | seed | RFC-0000 |
| `prompt-profile` | Prompt Profile | System prompts and behavioral configuration | seed | RFC-0000 |
