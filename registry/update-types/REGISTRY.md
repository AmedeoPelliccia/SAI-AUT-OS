# Registry — Update Classes

**Status:** Normative · **Layer:** Interoperability · **Spec:** v1.0.0-draft.1

Reservation rules: new entries MUST be added only via a ratified RFC
(see `spec/rfcs/`). Entries are never deleted — they are deprecated by
amendment and remain resolvable forever. IDs are lowercase kebab-case.

| ID | Name | Description | Status | Defined by |
|---|---|---|---|---|
| `memory-update` | Memory Update | Insertion, revision, or retirement of memory content | seed | RFC-0000 |
| `lora-adapter-promotion` | Adapter Promotion | Promoting trained adapter weights into service | seed | RFC-0000 |
| `rag-corpus-update` | RAG Corpus Update | Adding, superseding, or removing retrieval content | seed | RFC-0000 |
| `tool-permission-change` | Tool Permission Change | Widening or narrowing a tool binding | seed | RFC-0000 |
| `prompt-policy-update` | Prompt Profile Update | Changing system prompts or behavioral configuration | seed | RFC-0000 |
